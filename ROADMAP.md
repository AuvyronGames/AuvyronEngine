# AuvyronEngine — Roadmap

## Alpha 0.4.2 (source implementation)

- Packed `.auvyronasset` container and standalone Player loader.
- Scene editor with layout and theme options.
- Lua UI prototype: menu, HUD and buttons.
- FPS, jump, sprint, crouch and basic collisions.
- Camera, scene directional/point/spot light, primitive fire/explosion entities.

## Next milestones

- Stable MSVC CI and complete standalone runtime packaging smoke tests.
- Better editor docking/resize, saved layout presets and icon assets.
- Physics via Jolt or another production-grade open source physics engine.
- Multi-light shadows, physically based materials, postprocessing and real particle systems.
- Native Game UI / Canvas editor with sprites, textures, fonts and responsive anchors.
- More complete Lua event system, collision events, assets and runtime safety.
- glTF animations, audio, prefab/scene graph, resource streaming and asset compression.
- Package signatures and authenticated encryption (optional, with documented threat model).
- Full VitePress documentation on GitHub Pages.
