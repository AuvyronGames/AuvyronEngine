# Build Game — AuvyronEngine v0.4.2 Alpha

The standalone game is generated by the **AuvyronPlayer** target, without editor panels, ImGui, gizmos or the asset manager.

## Windows

1. Install Visual Studio 2022 with the C++ workload, CMake and Git.
2. Run `Build_Clean_Windows.bat` to compile both `AuvyronEngine.exe` and `AuvyronPlayer.exe`.
3. Run `Run_Editor.bat` and open your project.
4. Use Components / World Settings to set your skybox and camera.
5. Save and select **Project → Build Game** (or Ctrl+B).
6. Choose the game EXE name and an output folder outside the source project.

```text
MyGame_Windows/
  MyGame.exe
  MyGame.auvyronasset
```

The single `.auvyronasset` container includes the project manifest, main scene and project assets. No separate `.lua`, `.obj` or `.png` files are required next to your EXE. Scene, scripts, mesh and skybox content is loaded directly from the container on game launch.

**Important:** source code is packed and obfuscated, **not encrypted securely**. The loader must recover it in memory for gameplay; determined users can recover data. This is not protection for passwords, server secrets or proprietary anti-cheat logic.

Build output needs the Visual C++ redistributable if not linked statically. Release and smoke-test on an actual Windows machine before publishing.

See `PACKAGING_AND_UI.md` and `README.md` for format details and current limitations.
